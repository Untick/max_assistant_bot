## Описание сервисов

### 1. tg_gateway (Telegram Gateway)
- **Технология**: Aiogram 3.x
- **Назначение**: Прием входящих сообщений от пользователя
- **Функции**:
  - Идентификация по user_id
  - Обработка текстовых и голосовых сообщений
  - Управление FSM-диалогами
  - Обработка команд (/start, /help, /schedule, /tasks)

### 2. asr_service (Automatic Speech Recognition)
- **Технология**: Whisper (локально)
- **Назначение**: Транскрибация голосовых сообщений
- **Функции**:
  - Распознавание речи с сохранением пунктуации
  - Очистка артефактов речи
  - Нормализация текста

### 3. agent_core (LLM Agent)
- **Технология**: LangChain / LangGraph
- **Назначение**: Обработка запросов и генерация ответов
- **Функции**:
  - Использование open-source LLM
  - Строгий парсинг JSON
  - Fallback-механизмы
  - Извлечение сущностей
  - Валидация дат кодом
  - Контроль делового стиля
  - Защита от prompt injection
  - PII-фильтрация

### 4. mcp_server (Model Context Protocol)
- **Технология**: FastMCP
- **Назначение**: Предоставление инструментов для агента
- **Инструменты**:
  - calendar_read / calendar_create
  - availability_check
  - task_tools
  - meeting_notes
  - get_date

### 5. rag_service (Retrieval-Augmented Generation)
- **Технологии**: FAISS + SQLite FTS5 + Cross-Encoder
- **Назначение**: Поиск релевантного контекста
- **Параметры**:
  - Чанкинг: до 500 токенов
  - Top-k: 3
  - Порог сходства: 0.75
  - Гибридный поиск

### 6. scheduler_service (Планировщик)
- **Технология**: APScheduler
- **Назначение**: Автоматические напоминания и задачи
- **Функции**:
  - Напоминания: 48ч, 24ч, 10:00, 30мин
  - Ежедневная сводка
  - Автоперенос просроченных задач
  - Часовой пояс: МСК

## Поток данных

1. Пользователь отправляет сообщение → tg_gateway
2. Если голосовое → asr_service → текст
3. Текст → agent_core → анализ намерения
4. agent_core запрашивает контекст → rag_service
5. agent_core вызывает инструменты → mcp_server
6. mcp_server взаимодействует с Google Calendar/Tasks
7. Ответ формируется → tg_gateway → пользователю
8. scheduler_service отправляет напоминания через tg_gateway

## Хранение данных

- **PostgreSQL**: задачи, встречи, карточки встреч, история запросов, расписания
- **Redis**: FSM-память диалогов, кэш расписания
- **FAISS**: векторные эмбеддинги для RAG
- **Журналы**: трассировка, аудит, версионирование промптов
