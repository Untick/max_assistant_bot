# Personal Planner — LLM-агент персонального планирования

Telegram-бот для голосового и текстового управления расписанием, задачами и итогами встреч.

## Возможности

- Создание событий календаря с проверкой пересечений и буфером 120 минут
- Управление задачами: дедлайны, статусы, автоперенос просроченных с запросом причин
- Напоминания: за 48 часов, за 24 часа, в 10:00 дня встречи, за 30 минут
- Запросы расписания: «что у меня завтра», «свободен ли я в пятницу в 14:00»
- Контекстный поиск по истории встреч (RAG)
- Голосовой ввод с транскрибацией и сохранением пунктуации
- Часовой пояс всех операций: МСК

## Архитектура

| Сервис | Назначение |
| --- | --- |
| tg_gateway | Прием сообщений Telegram (Aiogram 3.x), FSM-диалоги |
| asr | Транскрибация голосовых сообщений (Whisper) |
| agent_core | LLM-агент (LangChain/LangGraph, open-source модель) |
| mcp_server | Инструменты (FastMCP): календарь, задачи, карточки встреч |
| rag | Гибридный поиск FAISS + SQLite FTS5, реранкинг |
| scheduler | Напоминания и сводки (APScheduler) |

Блок-схема взаимодействия: [docs/architecture.md](docs/architecture.md)
